# CS2 Skins Hub — панель управления виджетами

Тематический дашборд «хаб цен и статистики CS2» с расширяемой системой
виджетов на чистом JavaScript (ES6 modules, без сборщика и фреймворков).

## Как запустить

Модули (`type="module"`) не грузятся с `file://`, поэтому нужен любой
локальный статический сервер:

```bash
# вариант 1: расширение Live Server в VS Code — просто "Open with Live Server"

# вариант 2: Node
npx serve .

# вариант 3: Python
python3 -m http.server 5500
```

Затем открыть `http://localhost:<порт>/`.

Для публикации подходит любой статический хостинг (GitHub Pages,
Netlify, Vercel, Surge) — проект целиком статический, backend не нужен.

## Архитектура

```
index.html          — разметка страницы, подключает main.js как модуль
main.js             — инициализация Dashboard, навешивание обработчиков
                       на кнопки "Добавить виджет …" и статичные элементы страницы
js/
├── UIComponent.js       — базовый абстрактный класс виджета
├── ToDoWidget.js        — список задач (локальное состояние)
├── QuoteWidget.js       — «совет дня» (API)
├── PriceWidget.js       — живой курс + мини-график (API)
├── PlayerCountWidget.js — «игроков онлайн» (API)
└── Dashboard.js         — коллекция активных виджетов, addWidget/removeWidget
styles/
├── main.css         — токены, сброс стилей, layout, кнопки
└── components.css   — сайдбар, топбар, герой, виджеты, карточки скинов
assets/
└── placeholder.svg  — единственная "заглушка" для всех <img>
```

### ООП

- **`UIComponent`** — конструктор принимает `{ id, title }`, бросает
  ошибку при попытке создать напрямую (`new.target === UIComponent`).
  Метод `render()` собирает общую рамку (шапка, кнопки «свернуть»/
  «закрыть») и один раз вызывает переопределяемый `renderBody()`.
  `destroy()` — единая точка очистки: обрывает `AbortController`
  (это разом снимает все обработчики, повешенные с `{ signal }`,
  и отменяет незавершённые `fetch`), чистит таймеры/интервалы,
  убирает узел из DOM.
- **`ToDoWidget`, `QuoteWidget`, `PriceWidget`, `PlayerCountWidget`** —
  наследники, каждый переопределяет `renderBody()`/`onMount()`/
  `onDestroy()` под свою логику. Данные каждого виджета — приватные
  поля экземпляра (`#tasks`, и т.д.), наружу не торчат.
- **`Dashboard`** — не знает о конкретных классах виджетов, получает
  «реестр» `{ todo: ToDoWidget, quote: QuoteWidget, ... }` в
  конструкторе. `addWidget(type)` создаёт экземпляр из реестра,
  `removeWidget(id)` вызывает `destroy()` и убирает из коллекции.
  Добавление нового типа виджета не требует правки кода `Dashboard`
  (открытость/закрытость, полиморфизм — `Dashboard` одинаково зовёт
  `render()`/`destroy()` у любого наследника `UIComponent`).
- Удаление слушателей событий и виджетов делегировано вверх: клик по
  кнопке «×» ловит `Dashboard` через один обработчик на контейнере
  сетки, а не отдельный слушатель на каждой карточке.

## Источники данных (виджеты с API)

Реального бесплатного публичного API с ценами скинов CS2 или
поминутным онлайном без ключа и с открытым CORS не существует
(Steam Web API и Steam Community Market не отдают заголовки CORS для
браузерных запросов без собственного сервера-прокси). Поэтому для
двух обязательных «живых» виджетов выбраны реальные публичные API
того же типа данных:

| Виджет | Источник | Ключ | Что показывает |
|---|---|---|---|
| `PriceWidget` | [CoinGecko](https://www.coingecko.com/en/api) `simple/price` + `market_chart` | не нужен | курс BTC/USD и график за 24ч — тот же тип виджета «текущая цена + тренд», что в макете |
| `PlayerCountWidget` | [SteamSpy](https://steamspy.com/api.php) `appdetails?appid=730` | не нужен | агрегированная оценка активности CS2 (`ccu`), не поминутная статистика |
| `QuoteWidget` | [Adviceslip](https://api.adviceslip.com) `advice` | не нужен | случайный совет дня |

Итого 3 виджета работают с внешними API (требование — минимум 2).

## Ограничения

- SteamSpy обновляет данные не в реальном времени — это оценка, а не
  точный счётчик онлайна, о чём явно написано в самом виджете.
- CoinGecko публичное API имеет лимит запросов в минуту; при частом
  ручном обновлении может временно вернуть ошибку — виджет покажет
  состояние «ошибка» и позволит повторить попытку.
- Карточки скинов, коллекции и лента новостей на остальной части
  страницы — статичный демонстрационный контент по макету, не подключены
  к API (это не входит в обязательные 2 API-виджета, но при желании
  ленту новостей несложно подключить, например, к публичному JSON
  Reddit `r/GlobalOffensive.json`).
- Изображения — заглушки (`assets/placeholder.svg`), везде указан
  `alt="тут должно быть изображение"`: замените `src` на реальные
  картинки перед сдачей, если это требуется критериями оценки.
